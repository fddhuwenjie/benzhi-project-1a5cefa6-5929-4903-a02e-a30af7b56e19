# 排烟联动演练资格工作台

本项目面向建筑安全团队，用于完成排烟系统联动演练的资格裁定。工作台覆盖案件建档、冻结前方案预检、毫秒级设备事件采集、确定性规则诊断、连续偏差整改、定向复演、送审就绪清单与职责分离复核，以及不可变资格证书、证据来源和审计链逐项校验。

服务仅使用 Go 标准库，直接提供原生 HTML、CSS 和 JavaScript 页面，不需要 Node 构建链。业务数据默认保存在 `./data`，包括原子 JSON 案件快照、持久幂等响应索引、只追加审计帧和独立证书文件。

## 构建

```bash
go build ./cmd/server
```

## 运行

```bash
go run ./cmd/server -addr=127.0.0.1:19081 -data=./data
```

浏览器访问 `http://127.0.0.1:19081/`。默认监听地址是 `127.0.0.1:19081`，可通过 `-addr=127.0.0.1:<port>` 修改；未显式传入 `-addr` 时，也可通过 `PORT` 指定端口，服务将绑定到 `127.0.0.1:<PORT>`。

## 测试与自检

运行全部单元和 HTTP 适配测试：

```bash
go test ./...
```

运行使用临时数据目录和真实回环 HTTP 的完整业务自检：

```bash
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```

自检会建立案件，完成稳定摘要预检后冻结方案，制造一次超时失败，完成偏差登记和定向复演，再由独立复核员批准并逐项校验证书、证据来源、审计链及案件终态。命令完成后会主动关闭服务并退出。

## 关键业务约束

- 冻结命令必须携带当前草稿内容的 `precheck_digest`；内容变化或修订过期后必须重新预检。
- 设备事件按冻结角色约束类型，并原子校验毫秒级重复事件和 URI、SHA-256 引用一致性。
- 规则结果提供失败类别、候选事件、响应裕量和临界合格标记；定向复演只替换授权目标规则的证据。
- 每轮失败可在同一偏差下追加原因、措施和复演详情，所有规则合格且偏差关闭后才能送审。
- `GET /api/cases/{id}/requests/{request_id}` 可只读查询幂等回执；完整性校验和回执查询均不改变案件修订。
- 复核前实时生成就绪清单并检查建档人、冻结人和所有轮次记录人的职责冲突。

## 主要目录

- `internal/domain`：案件聚合、状态机、方案与事件不变量、证书摘要。
- `internal/qualification`：顺序、时限和证据完整性的纯确定性判定。
- `internal/store`：原子快照、幂等索引、摘要审计链和不可变证书。
- `internal/application`：按案件串行执行用例、并发修订校验和职责分离。
- `internal/web`：同源 JSON 映射和浏览器工作台。
- `cmd/server`：地址配置、依赖装配、优雅关闭与全流程自检。
